# Student Portfolio

A responsive, single-page portfolio built with React, Vite, and Tailwind CSS. It includes Home, About, Skills, Projects, Education, and Contact sections.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```

## Personalize

Replace the sample name, email, location, education, skills, and project descriptions in `src/data/portfolio.js` before publishing. The example profile and project entries are placeholders, not claims about the portfolio owner.

## Structure

- `src/components/` contains reusable page sections and navigation.
- `src/data/portfolio.js` contains editable portfolio content.
- `src/portfolio.css` contains the page styling and responsive layouts.
